基本设计思路：
	本系统采用前后端分离的架构模式，通过 RESTful API 进行数据交互。设计核心围绕“用户角色”与“功能模块”展开：
		架构层次设计：
			前端层：使用 Vue 3 框架构建单页面应用（SPA），负责页面路由、UI 组件渲染和用户交互逻辑。
			控制层 (Controller)：负责接收 HTTP 请求，解析 JWT 令牌进行安全校验，并分发业务逻辑。
			业务逻辑层 (Service)：实现核心业务规则，如权限判断、资源 visibility 设置、多表关联逻辑等。
			数据持久层 (Mapper)：利用 MyBatis 框架与 MySQL 交互，处理 SQL 映射。

		核心业务逻辑思路：
			权限与安全：通过 JWT (Json Web Token) 结合 Servlet Filter 实现登录状态维护。只有合法的 Token 才能访问非登录接口。
			资源可见性控制：针对教师发布的资源，设计了 visibility 字段（全部可见/仅本班可见），在 SQL 查询时根据当前登录学生的班级 ID 进行过滤。
			通知提醒机制：当教师回答问题后，系统向 notification 表插入记录，学生登录后通过轮询或刷新获取未读提醒。
